# Windows 客户端 0.2.5

运行 PortalLoginer-0.2.5-Setup.exe，可选择安装目录。升级沿用原目录；迁移目录需要先卸载。安装后从桌面打开 Portal Loginer。

## 首次配置

1. 连接校园 Wi-Fi 或网线。没有取得地址和路由时等待，不以已连通互联网作为登录前提。
2. 多个出口可指定一个，或跟随 Windows 默认路由。认证、探针和独立 DNS 使用同一出口。
3. 当前已联网时，检查预置校园认证服务器；按提示退出当前登录，重新取得认证参数。服务器不可访问时，连接校园网络，手动注销或等当前会话到期。
4. 探针取得有效跳转后填写账号密码，点击登录。账号验证、联网确认通过后才保存。失败或验证中切网不覆盖原账号。
5. 首次只有 Wi-Fi 时默认勾选指定 Wi-Fi，成功后保存绑定。关闭面板后托盘和后台继续运行。

## 日常操作

- **登录**：恢复自动认证，先尝试退出当前会话，再探测并登录。登出返回失败或超时不直接中止；以探测和认证结果为准。
- **退出登录**：注销，暂停本次开机自动认证。再次点击“登录”可恢复，下次开机不受影响。
- **退出程序**：关闭后台、托盘和面板。下次开机遵循开机自启设置。
- **关闭面板**：仅关闭面板。

默认每 30 秒检查主探针；有效跳转触发认证。主探针异常先尝试匹配当前地址的缓存，失败后尝试两个备用探针，每轮最多三次认证。接口确认成功而互联网探测仍异常时提示检查代理或更新后的登录参数，等待手动操作。

默认每次系统启动后网络就绪强制重登一次，可在高级设置关闭。睡眠唤醒、切网及后台重启不重复执行同一次开机重登。

高级设置提供检查间隔、失败重试间隔、开机强制重登、日志大小和详细日志。默认通知登录成功和网络错误，遵循系统通知设置。

## 卸载

从 Windows“已安装的应用”或开始菜单的卸载入口运行卸载器。先退出托盘程序。卸载删除程序、服务、启动项、快捷方式、配置、受保护的密码及日志；重新安装从初始配置开始。应用面板不提供卸载按钮。

## 本版验证范围

已通过自动测试、静态检查及正式构建。已在未登录校园 Wi-Fi 只读验证三个 Rust 探针取得有效 302，没有执行真实账号登录或注销。安装目录选择、完整卸载、开机重登与 TUN 仍需实际安装和校园账号验收。

程序尚未系统代码签名；自动更新和 macOS 版本尚未完成。`--preview` 仅预览，`diagnose-wifi <SSID>` 只发送无账号密码的诊断探针。

0.2.1：修复 Windows 通知设置查询异常被误当作禁用、通知发送前就去重的问题。账号页提供“测试 Windows 通知”，日志页显示最近一次通知处理结果。程序、安装器、窗口和托盘使用统一图标；保存配置或 DNS/配置属性变化不再重新计算网络稳定时间。

0.2.2：登录成功后保留设置页面，由用户自行关闭；成功提示明确账号密码已保存。“退出登录”保留账号、凭据和自启动设置，只暂停本次开机的自动认证；输入框留空表示不修改已保存密码。

0.2.3：卸载先检查设置和托盘是否退出，再停止服务、检查程序文件占用，随后清理数据和程序。卸载器自带清理组件；重复卸载会跳过已删除的文件或服务。安装器支持修复登记目录中的残缺安装，不再要求旧服务程序仍然存在。

若旧版卸载已中断，先退出所有旧安装、卸载窗口和托盘，然后运行 PortalLoginer-0.2.5-Cleanup.exe 清理；也可直接运行新版安装包修复原目录。清理程序会删除账号密码和配置，修复安装不会主动清除已有配置。

0.2.5：原“强制重新登录”按钮改为“登录”。登出失败后继续探测；有效跳转优先更新参数，探针异常时可用匹配当前出口的缓存继续认证。无缓存且探测已在线时只报告已在线，不声称完成了新密码验证。

0.2.5：新增“关于”页及窗口顶部版本号，可查看客户端版本、后台版本、项目主页和更新状态。稳定在线时每 10 次检测汇总一条日志（默认约 5 分钟），异常和认证结果立即记录。写日志不再读取配置文件，查看日志只读取末尾 16 KiB；日志页仅主动刷新时读取。
