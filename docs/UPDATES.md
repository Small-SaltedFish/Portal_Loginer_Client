# 更新与镜像下载

更新源固定为本仓库的 GitHub Releases。不使用更新签名、私钥或额外加密；下载使用 HTTPS，完整性使用 SHA-256。

## 下载

1. 从 `https://api.github.com/repos/Small-SaltedFish/Portal_Loginer_Client/releases/latest` 获取正式版版本号、更新 ZIP 地址、大小及 GitHub 提供的 digest。跳过草稿、预发布、相同版本，拒绝降级及其他仓库地址。
2. 优先通过正常联网路径下载。后台读取绑定用户的系统代理及持久化代理变量；认证请求仍独立直连。
3. GitHub 下载失败时，并发对 GHFast、ghproxy.net、GH-Proxy 的真实 ZIP 最多 64 KiB 片段测速，按吞吐量排序，失败自动换站。备用连接绕过普通代理；TUN 仍由系统路由控制。只接受 HTTPS、限定站点、有效 Range 和 ZIP 数据，不把错误网页当下载文件。
4. 支持中断续传；服务端不支持 Range 时重新下载。完整文件大小和 SHA-256 必须与官方接口一致。
5. 官方接口暂不可达时，使用此前存入受保护目录的官方版本及校验值继续下载。没有缓存时等待恢复，不从第三方镜像同时接收安装包和校验值。

镜像可用性每次实测，不保证固定站点长期可用。SHA-256 与 GitHub 官方返回值直接兼容。[GitHub 接口说明](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)

## 安装与恢复

- 正常联网后自动检查，随后约每天一次并加入随机偏移；失败 15 分钟后重试。关闭自动更新后仍可手动检查、下载并安装。
- 等待认证事务完成、设置窗口关闭、全屏或演示状态结束。安装、卸载与更新共用互斥锁。
- 独立更新进程在受保护目录再次校验大小和 SHA-256，只解压固定七个文件；拒绝路径穿越、符号链接、额外文件、超限解压和非 EXE 数据。
- 保留旧版文件，逐文件原子替换，服务最后切换。检查新服务报告的版本；失败恢复旧版，暂停该版本的自动重试，允许用户手动重试。
- 独立守护进程处理更新进程意外退出或挂起；系统重启时也检查未完成事务。保留上一版本备份。
- 保留账号、密码和设置；恢复托盘，不打开设置，不弹日常更新通知，不重新请求管理员授权。

本地测试覆盖 HTTP 续传、错误 Range/HTML、版本与校验值、ZIP 路径限制、文件切换和恢复。真实服务升级、断电和游戏全屏场景仍需实机验收。

## 发布

依次运行 dev.ps1 test、dev.ps1 build、package-dev.ps1 -SkipBuild、package-update.ps1 和 publish-release.ps1。提交源码后使用 publish-release.ps1 -Publish 发布。

Release 标签为 v<版本>，包含安装包、清理器、专用更新 ZIP、SHA-256 文件及本地检查清单。客户端直接读取官方 Release 接口，不依赖清单附件或签名文件。不能将开发 ZIP 用作更新载荷。

0.2.5 及以前需先手动安装 0.2.6，此后才具备自动更新能力。程序暂未做操作系统代码签名。
