# 确认后的产品逻辑

2026-11-08 用户确认。本文件是后续实现依据，不表示当前 0.1.4 已实现全部流程。原插件用于核对协议、加密和请求行为，产品流程按本文件调整。

## 首次配置

1. 安装包附带当前学校的认证服务器 IP、bras 等已确认引导信息。不能把旧示例会话 IP、MAC、VLAN 当作动态参数。现场已确认的服务器为 192.168.199.200，bras 为 mlyx。
2. 网络出口指已连接、取得地址且具备路由的物理接口，不要求互联网已通。无出口就等待，提示未连接任何网络。
3. 一个出口默认使用；多个出口让用户选择，或选择跟随 Windows 默认路由。一次事务固定出口，DNS、探针、门户和全部认证接口必须一致，不能静默换到另一接口。
4. 首次只有 Wi-Fi 连接时，默认勾选指定 Wi-Fi 自动认证；认证成功后才保存绑定的 SSID。用户可取消该限制。
5. 已在线：检查预置认证服务器是否响应。可响应时提供注销按钮，说明需要注销后获取新参数并验证账号。无响应时提示连接目标校园网络、手动退出宽带认证或等待有效期结束后再配置。
6. 未在线：依次尝试三个探针，获得有效 302 后取得整套参数，进入账号配置。三个都异常且没有有效跳转，报网络异常，提示检查 TUN 等配置并等待。
7. 配置账号密码、认证、确认结果并保存参数缓存。不得把已有互联网连接直接当作新填写密码已经验证。

## 日常监测

- 保存一个校园账号，密码独立受保护保存。参数缓存与网络身份关联。
- 开机后目标网络首次就绪，可强制注销并重新探测登录，默认开启；每次系统启动最多触发一次，不因睡眠唤醒、切网或后台重启反复注销。
- 默认每 30 秒检查主探针。正常不操作；302 更新参数并登录。
- 主探针异常时，先用匹配当前网络的缓存参数尝试登录。缓存认证失败再使用两个备用探针取得新参数并认证。
- 每轮总共最多三次认证尝试，包含首次及缓存认证尝试，不是每个探针各三次。按失败重试间隔执行；失败后报错并等待后续检查或网络变化。
- 两个备用探针均异常时报告网络错误。
- **认证接口已确认，但仍无法确认互联网连接时**：显示“当前未连接互联网，请检查代理配置或登录参数可能已更新”，进入需要手动操作的状态；不因接口成功继续宣称网络正常，不反复自动登录。

## 用户操作

- 登录（原“强制重新登录”）：恢复本次开机自动认证，先尝试登出，再重新探测并登录。登出失败或超时不能单独中止流程，不将登出失败直接当作“已经登出”；以后续有效探测和认证结果为准。
- 退出登录：注销并暂停本次开机自动认证，直到用户再次点击“登录”；下次开机不受本次暂停影响。
- 开机自启复选框：控制后续系统启动时是否运行。
- 退出守护程序/退出程序：停止本次运行的检测与认证，关闭后台、托盘及面板。下次启动仍遵循开机自启配置。
- 关闭面板：仅关闭面板，后台与托盘继续工作。

## 配置与通知

- 常规：账号、密码、出口、指定 Wi-Fi、自启动、通知设置。
- 默认通知：登录成功和网络错误。错误去重；重试不反复通知；遵循系统通知及勿扰规则。
- 高级：在线检查间隔、失败重试间隔、开机强制重登、日志最大保存大小、详细 debug 开关。
- 日志须包含实际接口、源地址、DNS、耗时、HTTP 和校验结果，隐藏密码、密文、完整账号及非必要会话信息。

## 安装与卸载

- 完整安装包内置卸载器，注册到 Windows“已安装的应用”，程序内不提供卸载按钮。
- 彻底卸载应删除程序、服务、启动项、快捷方式、配置、凭据、日志和应用专属设置，达到重新安装时的初始状态。
- 0.2.0 内置卸载器并登记 HKLM 64 位卸载信息；新增清理配置、凭据和用户专属启动设置。实际安装卸载尚待验收。
- 0.2.0 安装提供目录选择，服务、程序定位、快捷方式和卸载使用安装路径。升级沿用旧目录，更换目录须先卸载。后台为 Windows GUI 子系统程序，安装调用不再创建控制台黑框。

2026-11-08 补充：首次保存并登录成功后不自动关闭面板，交由用户关闭。退出登录只注销当前会话并暂停本次开机自动认证，保留账号密码和开机自启设置。密码输入框不回显已保存的密码，留空不会删除密码。
